# 微信输入连接器

手机微信文字或现成语音转写，写入 Windows 当前输入框，并回复连接器状态。独立 WPF 桌面客户端，无需 OpenClaw 中转，无需绑定目标应用。

当前版本为 0.2.0。普通输入框已经有本地实际输入验证；各应用兼容性、焦点竞态和长时间运行仍需分别验收。手机切换 Codex / Antigravity 及编号菜单尚未接入。

## 桌面使用

- 常驻绿色悬浮点，单击展开状态条，拖动移动；普通消息不自动展开窗口。
- 点击“历史”或双击托盘图标，打开桌面管理窗口。“历史记录”左侧是消息列表，右侧是完整正文，可选择、复制。历史只在电脑查看，不补写、不重发。
- 设置页管理自动输入、输入后回车和悬浮窗置顶。关闭管理窗口后，连接器继续运行。查看连接器时不向自身窗口输入；新消息仍保存。
- 右键悬浮窗或点击更多，可打开历史、设置、隐藏悬浮窗或退出。隐藏后可从托盘恢复。
- 需要补写时，先点击外部输入框，再按 Ctrl+Alt+V，处理最早一条可执行的待输入记录。状态文字不会触发补写。
- 新安装默认关闭额外回车，已有用户设置保留。回车作用由目标应用决定。通用按键后端拒绝自动派发含换行或制表符的文本，支持文字插入的标准 Edit/RichEdit 后端保留原文本。

## 微信回执

- **远程屏幕截图回传**：在手机微信中发送“截图”、“截屏”、“看屏幕”、“屏幕”或“/截图”，电脑自动捕获当前桌面高分辨率画面，经 AES-128-ECB 密文加密后通过腾讯微信官方 CDN 安全回传到微信对话。悬浮窗动态展开展示回传状态。
- **悬浮窗与托盘快捷截图**：右键悬浮窗或右键系统托盘图标，点击“📸 截取屏幕发微信”，可随时手动截取屏幕并推送给绑定的手机微信。

- 派发后回复“已派发到当前输入框”，不做写入后文字回读，不把派发等同于实际写入成功。
- 原绑定私聊发送 /状态，查看连接、自动输入/回车开关、待处理及待发回执数量；查询不会写入电脑。
- 单条结果不明时不重发，后续新消息继续；历史积压不自动补写。回执有限重试，重试不重新执行输入。
- 普通回执不回显正文、窗口标题、路径或凭据。没有有效会话上下文时无法发送回执。
- 不自动改写剪贴板。只有用户在历史窗口点击“复制正文”时写入剪贴板。

## 本地安装与启动

使用项目私有工具链，不修改全局 .NET 配置：

```powershell
./scripts/dev.ps1 restore WeChatInputConnector.sln -r win-x64
./scripts/dev.ps1 test WeChatInputConnector.sln --no-restore
./scripts/dev.ps1 publish tools/Connector.Probe -c Release -r win-x64 --self-contained true --no-restore -o artifacts/desktop-hardened
./scripts/install-local.ps1
```

安装脚本复制独立版本到当前用户 LocalAppData/WeChatInputConnector/bin，并保存版本指针；根目录“启动微信连接器.bat”启动该版本。程序与数据默认存放在专用用户目录，ACL 限制其他普通用户写入；不更改开发仓库或整个磁盘的权限。

首次启动在桌面设置页扫码，手机确认；需要验证码时由用户本人输入。旧仓库 .local 数据只在显式迁移时读取，不向祖先目录搜索凭据：

```powershell
# 先退出旧实例；仅在目标用户目录尚无绑定身份时执行。
./scripts/install-local.ps1 -MigrateFrom 'D:\project\01-自研项目\wechat-input-connector\.local'
```

迁移保留原目录，经过单实例检查与完整暂存后才发布身份；迁移中断会阻止普通启动，可使用原迁移命令重试。不要在新版运行时重新启动旧版。

## 数据与可靠性边界

- 凭据和事件采用 DPAPI CurrentUser 加密；当前用户身份下的其他进程不在隔离边界内。
- 保存采用密文临时文件、落盘和替换，最多保留上一代密文备份。损坏或版本不兼容时明确失败，不静默回退旧游标并补输。
- 终态正文按 7 天、1000 条、UTF-8 10 MiB 上限清理；活动队列最多 1000 条且正文不超过 UTF-8 4 MiB。实际快照另预留账号、回执和元数据空间。旧积压不静默删除；容量满时明确拒绝新增自动输入。
- 清理正文后保留去重墓碑，最长 30 天、最多 10000 条。这是有界去重，不承诺跨应用“恰好一次”。
- 输入执行在受控 helper 的 MTA 线程中完成，父进程负责超时、取消、阶段保存和子进程清理；失败后不换后端自动重试。
- 只有正常状态保持绿色；失效或终止如实显示。日志和诊断只记录固定状态、计数及错误类型，日志和阶段档案有轮换上限。
- 回退旧版本必须使用升级前的旧格式数据备份。旧程序不能直接读取新版版本封套；回退可能缺少升级后的处理状态，须先关闭自动输入并核查，不能承诺无损自动回退。

## 验证与维护

```powershell
./scripts/dev.ps1 test WeChatInputConnector.sln --no-restore
./scripts/dev.ps1 build WeChatInputConnector.sln -c Release --no-restore
```

Windows CI 包括锁定还原、依赖漏洞检查、测试与 Release 构建。自包含发行版本需要随 .NET 安全更新重新发布。版本校验值仅帮助核对文件，不能代替发布者签名。

架构分层：Connector.Core 管理状态、历史和回执；Connector.WeChat 管理协议、身份和上下文；Connector.Windows 管理输入及加密存储；Connector.Probe 装配桌面界面与会话。没有数据库、常驻服务或额外网络监听。
