# 微信文本连接器

独立 Windows 客户端，将绑定用户在微信 ClawBot 私聊发送的文字写入符合条件的当前输入框。

当前阶段：P0 技术验证。真实扫码、消息字段映射和记事本端到端测试通过前，不宣称产品已可用。

开发环境使用项目内 `.tools/dotnet`，不修改系统 PATH。通过 `scripts/dev.ps1` 执行开发命令。

设计和实施清单位于 `docs/superpowers`；实测记录位于 `docs/verification`。凭据和诊断数据不纳入 Git。

当前版本仍有待修复的安全问题，不建议用于敏感信息或无人值守输入：

- 通用按键输入将换行转换为 Enter，可能触发目标应用发送消息、提交表单或执行终端命令。
- 焦点、可编辑状态检查存在放行过宽及忽略异常的路径，不能保证未知控件被拒绝。
- 悬浮窗接收流程尚未完整接入消息时效限制、输入结果持久化、结果不明时暂停和正文到期清理；不能视为已完成可靠性验收。
- 本地凭据和消息使用 Windows DPAPI 当前用户加密；它不能隔离同一 Windows 用户权限下的其他程序。输入到目标应用后，文字由目标应用保存、同步及处理。

无需选择或绑定目标应用是产品要求；修复上述问题应保持跟随当前输入焦点的使用方式。远程源码仓库不包含 `.local/`、`*.dpapi`、SDK、运行日志及构建产物。此处风险来自源码检查，尚未完成完整渗透测试和跨应用实机安全验收。
