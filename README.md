# 微信输入连接器 (WeChat Input Connector)

> **手机微信文字或现成语音转写，写入 Windows 当前输入框，并回复连接器状态。**
> 独立原生客户端 · 免应用绑定 · 极简灵动小药丸 · 自动回车 · 无需 OpenClaw 中转

当前仍是 P0 验证版本，不能据此承诺所有应用兼容或端到端延迟。手机切换 Codex / Antigravity 尚未实现；状态回执仅预留切换适配器接入口。

## 微信状态回执

- 输入派发后简短回复“已派发到当前输入框”；不做写入后文字回读，也不再提示“尚未确认”。无法派发则如实回复原因，不把派发等同于文字已写入。
- 在原绑定私聊发送 `/状态`，查询连接、自动输入/回车开关、待处理及待发回执数量。查询指令不会写入电脑。当前应用/输入框定位尚未接入适配器时显示“未确认”。
- 本地输入开关变化会回报实际状态；单条结果不明时保留记录且不再重发，后续新消息继续尝试输入，历史积压不会自动补写。
- 一条消息通常只回一条结果，不回显正文、路径、窗口标题或凭据。回复失败只有限重试回执，绝不重新执行输入。
- 回执依赖有效会话上下文。首次使用、上下文过期或断网后，可发送 `/状态` 建立新的查询上下文；电脑离线时不能即时通知微信。
- 状态协调、协议客户端、输入执行器和回执发件循环分别负责各自工作。输入状态和待发回执同次加密保存。

已知限制：现有通用输入执行器仍有焦点判断过宽和换行/自动回车触发目标动作的风险；增加回执不等于这些问题已修复。建议关闭自动回车后在普通文档中验证。DPAPI 不能隔离同一 Windows 用户权限下的其他程序。

## 🌟 核心特性

- **💊 极简“灵动小药丸”悬浮窗**
  - **闲置静默**：平时自动收拢为仅 **36×36 像素** 的微型悬浮珠，带微光呼吸绿点，可拖拽至屏幕任意角落，完全不遮挡工作。
  - **动态唤醒**：手机微信发来语音或文字时，小圆珠平滑伸展为胶囊药丸，大字显示打字内容，停留 **3 秒** 后自动优雅缩回。
  - **精致设置**：同款暗黑磨砂玻璃设置卡片，配备现代化 iOS / Fluent 风格滑动开关，偏好自动本地持久化。
  - **托盘驻留**：支持一键最小化至 Windows 系统任务栏托盘，安静守护。

- **直接输入 (Direct Injection)**
  - 通过原生输入机制写入文本；端到端速度和跨应用兼容性需要分别实测。

- **⏎ 智能自动回车发送 (Auto-Enter)**
  - 手机语音转写打入输入框后，可毫秒级自动追加按下 `Enter`（回车键），在微信电脑版、QQ、飞书、搜索框或终端中直接发送。
  - 支持在设置面板中随时一键开启或关闭。

- **🎯 免应用绑定，光标停在哪就打在哪**
  - 无需繁琐配置目标进程或指定窗口。无论是记事本、微信 PC、Office Word、浏览器搜索栏、代码编辑器，还是财务/ERP 填表控件，光标在哪个输入框闪烁，文字就直接打入哪里。

- **已有保护机制（仍需实机验收）**
  - **安全拦截**：遇到密码输入框或只读控件自动跳过输入，防止敏感信息误入。
  - **保护剪贴板**：基于底层虚拟硬件按键注入，不污染、不篡改用户的剪贴板。
  - **全局快捷补打**：若发消息时光标未对准，随时切换回目标输入框按下 **`Ctrl + Alt + V`**（或点击药丸文字）即可一键补录。
  - **DPAPI 本地安全加密**：微信登录凭证和会话状态均使用 Windows DPAPI 本地当前用户密钥加密，不上传任何第三方服务器。

- **🔌 腾讯官方原生协议直连**
  - 基于腾讯微信官方底层 iLink Bot 协议（长轮询），无需额外部署 OpenClaw 框架，无需公网 IP 或云服务器，无第三方中转风险。

## 🚀 快速上手

### 1. 启动应用
- 直接双击运行项目根目录下的 **`启动微信连接器.bat`**，或运行发布包中的 **`Connector.Probe.exe`**。
- 程序首次启动时，胶囊药丸会向下展开二维码抽屉。

### 2. 扫码绑定
- 使用手机微信扫描界面中的二维码；
- 在手机微信上点击确认授权（若提示输入数字验证码，在抽屉中输入确认即可）；
- 登录成功后，二维码抽屉将秒速自动收起，悬浮条缩为 36px 微型小圆珠，指示灯变绿进入就绪状态。

### 3. 开始打字
- 鼠标点击电脑上要输入的任意软件输入框（如微信 PC 聊天框、Word 文档、搜索框）；
- 手机微信直接向绑定的小助手发送**语音**或**文字**；
- 电脑端瞬间完成文字上屏并自动回车发送！

## ⌨️ 快捷操作与交互

| 交互操作 | 功能效果 |
| :--- | :--- |
| **鼠标拖拽小圆珠 / 药丸** | 自由移动并停靠在屏幕任意边缘或舒适位置 |
| **单击微型悬浮珠** | 手动展开胶囊药丸查看当前状态 |
| **右键小悬浮珠 / 点击 ⚙** | 唤出暗黑磨砂玻璃「偏好设置卡片」 |
| **`Ctrl + Alt + V`** | 全局补打快捷键（将最早一条可执行的待输入文字打入当前光标处，跳过已拒绝或已处理条目） |
| **点击展开药丸上的文字 / `↵` 按钮** | 重新打入当前光标所在输入框 |
| **点击 `—` 或 `✕`** | 收起为微型悬浮珠 / 最小化到系统托盘 |
| **双击任务栏绿色托盘图标** | 随时唤出或隐藏悬浮窗 |

## 🛠️ 本地开发与构建

项目采用纯净独立的工具链体系，开发环境使用项目私有 `.tools/dotnet`，不修改全局系统环境。

### 运行全量测试
```powershell
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 test
```
测试覆盖协议解析、身份和上下文校验、输入状态、回执队列及恢复；当前数量以全套测试输出为准，不能替代跨应用实机验收。

### 构建项目
```powershell
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 build
```

### 发布独立免运行库版本 (Self-Contained)
```powershell
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 publish tools/Connector.Probe/Connector.Probe.csproj -c Release -r win-x64 --self-contained true -o artifacts/simple-input
```
*编译输出包含完整的 Windows x64 .NET 运行时，在任何 Windows 10/11 电脑上均可双击直接启动。*
