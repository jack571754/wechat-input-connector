# 实施计划 · 极简“灵动小药丸”UI与极速注入上线

> **目标**：将原工程化测试窗口彻底重构为类似 macOS 灵动岛 / 胶囊药丸的高质感极简悬浮条（Pill Widget），同时接入已验证的 2ms 直接注入引擎与系统托盘驻留，兼顾极致颜值与生产力输入。

---

## 一、涉及模块与文件清单

- **`src/Connector.Windows/FocusedInputProbe.cs`**：已完成 Direct Injection（极速直接注入）并在单元测试中覆盖，彻底消除 600ms 进程启动开销。
- **`tools/Connector.Probe/PillWindow.cs`（新文件）**：
  - 基于 WPF 构建无边框、半透明磨砂黑/白胶囊药丸（360×44px，圆角 22px，阴影 DropShadow）。
  - 支持随意拖拽、置顶/不置顶、呼吸指示灯（微信绿 `#07C160`）。
  - 状态智能折叠：已登录仅留药丸；未登录时平滑展开二维码抽屉；收到转写时高亮最新内容。
  - 右键极简菜单：[自动输入: 开/关]、[置顶显示]、[重新扫码]、[最小化到托盘]、[退出]。
- **`tools/Connector.Probe/TrayManager.cs`（新文件）**：
  - Windows 系统托盘管理，支持双击托盘图标隐藏/呼出药丸，托盘右键退出。
- **`tools/Connector.Probe/Program.cs`**：
  - 更新入口，将 `Forms.Application.Run(new ProbeForm(...))` 迁移至 WPF `Application.Run(new PillWindow(...))`。
- **`tests/Connector.Windows.Tests/`**：保持所有 71 个单元测试全部通过。

## 二、分步实施任务 (Tasks)

### 任务 1：构建系统托盘与生命周期管理 (`TrayManager.cs`)
- **目标**：实现 Windows 系统托盘驻留，提供托盘图标、气泡提示、双击呼出/隐藏、托盘右键菜单。
- **验证方式**：编译并验证 `TrayManager` 基础实例与事件分发。

### 任务 2：实现 WPF 极简灵动药丸悬浮窗 (`PillWindow.cs`)
- **目标**：
  - 创建纯代码 WPF 现代窗口，设置 `WindowStyle=None`, `AllowsTransparency=True`, `Topmost=True`。
  - 实现胶囊药丸视觉体系：深色暗影磨砂背景 `#1E1E22`、圆角 22px、微信绿状态呼吸点、最新文字单行滚动/省略展示。
  - 实现拖拽移动与状态响应（连接中、已连接、写入中、待补打）。
  - 实现扫码抽屉展开/折叠面板，扫码成功后自动优雅收回药丸。
  - 绑定全局快捷键 `Ctrl+Alt+V` 补打逻辑与点击文字快速重新输入。
- **验证方式**：单元测试通过，界面正常加载，状态自适应切换。

### 任务 3：集成 Direct 极速直接注入与启动入口迁移 (`Program.cs`)
- **目标**：
  - 在 `Program.cs` 中切换主运行循环为 WPF 应用程序生命周期。
  - 将微信长轮询事件流与 Direct Injection 极速注入（2ms 耗时）完整接入 `PillWindow`。
  - 确保单一实例互斥锁与数据目录持久化完全正常。
- **验证方式**：全量单元测试通过（71/71），构建无报错。

### 任务 4：打包 Self-Contained 独立可执行程序并验证
- **目标**：
  - 发布最新的独立免运行库版本到 `artifacts/p0-current/`。
  - 验证双击桌面图标正常启动精致药丸悬浮窗，状态正常显示为已连接。
- **验证方式**：双击启动，测试手机发文字/语音实时秒速打上屏幕。
