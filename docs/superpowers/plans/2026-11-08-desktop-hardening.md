# 桌面交互与最小加固实施计划

> 执行方式：当前会话直接实施，遵循 superpowers:executing-plans 和 test-driven-development。用户已确认桌面设计并要求开始执行，无需再次确认。

目标：保持自动输入及绿色常态，补齐输入安全、故障隔离、只读历史、长期运行和可回退发行。

依据：`../specs/2026-11-08-desktop-interaction-design.md`、`../../verification/2026-11-08-hardening-assessment.md`。

约束：不绑定应用、不新增手机历史功能、不恢复结果回读和结果不明自动暂停；不引数据库、常驻服务或管理员输入。结果不明不重发，后续新消息继续。保留当前工作区其他任务修改，特别是 ILinkClient 与图片上传测试。不推送远程。

## Task 1：单次输入隔离及目标/按键语义

文件：Connector.Windows/FocusedInputProbe.cs、ProbePolicies.cs，Windows 测试。
- [ ] 先写失败测试：任意元素不代表可编辑目标；控件比较失败必须拒绝；Unicode 后端多行不能变成提交；显式回车前目标变化不能派发；helper 请求传递回车选项。
- [ ] 运行新测试确认失败，再统一 helper 执行路径、使用 MTA、保持 Job/超时/阶段保存、派发前核对真实目标；修复异常吞掉；预派发失败为待输入、可能已执行为结果不明，不自动换后端。
- [ ] 运行 Windows 测试；提交本任务文件。

## Task 2：Core 历史视图、容量恢复与有界记录

文件：Connector.Core、ReceiptSession、Core 测试。
- [ ] 先写失败测试：历史按当前身份过滤、只读、状态准确、完整正文；完成记录有界清理保留去重标记；活动队列不静默丢失；容量恢复只清 OutboxFull；失败原因保留。
- [ ] 实现轻量只读历史模型、固定保留上限及有界去重墓碑；保留输入前落盘和串行处理。不改变回执重试及旧 JSON 兼容。
- [ ] 会话补充退避抖动、异常快速空轮询的最低间隔及脱敏诊断；不引独立持久化消息队列。
- [ ] 全套测试通过后提交。

## Task 3：加密文件恢复与专用用户目录

文件：ProtectedFile.cs、新增 DataDirectory.cs、相关 Windows 测试，Program 入口。
- [ ] 先写失败测试：损坏数据明确失败、上一代密文保留、文件大小上限、存储版本及旧格式兼容、迁移路径/权限边界。
- [ ] 实现有界密文备份及安全读取；默认用户数据目录，显式迁移旧目录，用户目录 ACL 最小化；不改开发仓库或全盘 ACL，不自动回退旧游标并补写。
- [ ] 设置原子保存、日志/阶段档案轮换；删除未接入入口的旧 ProbeForm。运行测试及构建后提交。

## Task 4：单窗口桌面界面

文件：PillWindow.cs、SettingsWindow.cs、TrayManager.cs、新增 DesktopWindow.cs、只读历史绑定。
- [ ] 使用现有 Core 历史模型与设置操作；新增普通桌面窗口，历史/设置两页，列表＋完整正文＋复制，不增加搜索/筛选/重发。
- [ ] 悬浮点/状态条非激活，状态点击不补写、拖拽阈值、消息到来不展开、位置约束；统一托盘入口，删除过时异常暂停项，保留 Ctrl+Alt+V 手动补写。
- [ ] 使用可键盘操作控件，正常窗口标题栏/任务栏、长文本可读、新消息不改选择；本进程前台不输入，关管理窗口继续收件。
- [ ] Release 构建及本机可见界面验收，提交。

## Task 5：审阅、发行与运行验证

文件：Windows CI、启动脚本、README、验证记录。
- [ ] 增加版本及提交标识、Windows CI（锁定还原、依赖审计、测试及 Release 构建）、有界脱敏日志和独立发行目录。
- [ ] 整批独立审阅，重要问题用失败回归测试修复；全套测试及 Release 构建通过后发布。
- [ ] 备份旧 DPAPI 状态，安全迁移，替换本机实例；验证进程、连接及桌面入口。保留旧版回退，不自动推远程。
- [ ] 手工验证真实焦点和输入；8–24 小时长稳及未完成的硬件/DPI 场景如实列为待验收，不用单测或派发计数冒充。

## 审查重点

取消/崩溃发生在派发前后；前台窗口/控件变化；无转写与超长文本；清历史不能破坏去重；其他任务并行修改及旧版数据恢复。
